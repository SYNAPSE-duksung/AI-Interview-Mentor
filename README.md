## 프로젝트 배경
- **문제 정의**: 기존 AI 면접 서비스는 단순한 질문 목록 제공에 그쳐, 답변에 대한 구조화된 피드백이나 심층적인 꼬리질문이 부족했습니다.
- **목표**: 단순 프롬프트 엔지니어링을 넘어, 도메인 데이터로 학습된 자체 평가 모델(모델 엔지니어링)을 기반으로 멀티턴 꼬리질문과 정량적 피드백을 제공하는 차별화된 서비스를 구축했습니다.

---

## 핵심 기능

| 기능 | 설명 |
| :--- | :--- |
| **맞춤형 면접 세팅** | 지원 회사와 직무를 입력하면 Gemini 3.1 Flash-Lite가 인성/직무 맞춤 질문을 생성하고, 평가 핵심 키워드 3~5개를 추출합니다. |
| **실시간 음성 인터뷰** | 생성된 질문을 gTTS로 음성 출력하고, 사용자의 음성 답변을 Whisper (small) 모델을 통해 텍스트(STT)로 변환합니다. |
| **AI 답변 정량 평가** | 파인튜닝된 EXAONE-4.0-1.2B 모델이 지원자의 답변을 분석하여 **두괄식 여부, 분량, 핵심 키워드, 논리 구조**를 정량적으로 평가합니다. |
| **종합 결과 리포트** | 턴별 상세 점수 및 피드백과 함께, Gemini를 활용한 개선된 모범 답변과 심층 꼬리질문을 웹 대시보드로 제공합니다. |

## 전체 시스템 구조 및 파이프라인

서비스 런타임(매 세션) 파이프라인은 다음과 같이 동작합니다.

1. **입력**: 기업명 및 직무 입력
2. **질문 생성**: Gemini API를 통한 직무별 맞춤 질문 생성
3. **음성 입출력**: TTS(음성 출력) 및 Whisper STT(음성 인식) 연동
4. **답변 평가**: EXAONE-4.0-1.2B QLoRA 파인튜닝 모델을 통한 정량 평가
5. **결과 피드백**: 꼬리질문 생성 및 최종 리포트(개선 답변) 제공

## 데이터 구축 및 모델 파인튜닝

### 1. 데이터 파이프라인
- **데이터 확보**: AI Hub 채용면접 인터뷰 데이터(84,134건) 중 7개 직군 비율을 유지하는 층화 추출로 총 1,999건 샘플링
- **라벨링**: Gemini 3.1 Flash-Lite를 활용하여 두괄식, 논리구조, 키워드, 분량에 대한 JSON 라벨 자동 생성 파이프라인 구축
- **Gold Set 구축**: 모델 검증을 위해 팀원 4인이 교차 라벨링을 진행, 주관적 지표의 특성을 감안해 ±1점 허용 기준(80.4%)을 신뢰성 지표로 채택

### 2. EXAONE QLoRA 파인튜닝
- **베이스 모델**: EXAONE-4.0-1.2B
- **학습 방식**: 4-bit NF4 기반 QLoRA 파인튜닝 (전체의 약 0.497%, 6.39M 파라미터만 경량 학습)
- **산출물**: 25.6MB 초경량 LoRA Adapter 생성 및 Hugging Face Hub 배포

## 주요 평가 결과

파인튜닝된 EXAONE 모델은 약 2,000건의 도메인 데이터만으로 대형 모델 대비 우수한 성능을 입증했습니다.

| 평가지표 | Fine-tuned (EXAONE) | Base | GPT-4o-mini |
| :--- | :---: | :---: | :---: |
| **파싱 성공률** | **100%** | 98.0% | 100% |
| **두괄식 정확도** | **0.721** | 0.447 | 0.692 |
| **분량 판단 정확도** | **0.886** | 0.746 | 0.811 |
| **논리구조 평균오차 (MAE)** | **0.493** | 1.467 | 0.597 |
| **논리구조 순위상관 (Spearman)** | 0.339 | 0.191 | **0.432** |
| **논리구조 가중일치도 (Quadratic Kappa)** | **0.387** | 0.014 | 0.310 |
| **키워드 F1 Score** | **0.277** | 0.018 | 0.037 |

- 7개 핵심 지표 중 6개에서 Base 모델 및 GPT-4o-mini를 능가했습니다.
- 특히 **키워드 F1 Score**에서 GPT-4o-mini 대비 약 7.5배 높은 성능을 보였습니다.

## 트러블슈팅

- **라벨 신뢰도 이슈**: 모델의 논리구조 채점 편차를 해결하기 위해 팀원 4인 교차검증(Gold set)을 거쳐 프롬프트를 개선했습니다.
- **로컬/서버 연동**: 로컬 실행 한계를 극복하기 위해 Google Colab을 FastAPI+ngrok 서버로 분리하여 API 호출 구조로 전환했습니다.
- **턴별 평가 키워드 누락**: 생성된 직무 키워드가 평가 모듈에 전달되지 않던 로직을 세션 상태에 저장·관리하도록 수정했습니다.
- **학습 불안정**: 학습 초반 높은 Learning rate로 발생한 Loss 상승 문제를 LR과 epoch을 재조정하여 안정화했습니다.
